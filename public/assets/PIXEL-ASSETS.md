# Pixel Desktop Assets

Visual direction: https://os.henryheffernan.com/ (typography and icon inspiration only; no assets copied from that site).

- Pixelated MS Sans Serif regular and bold: 98.css 0.1.20, https://github.com/jdan/98.css. Bundled WOFF2 files, licensed under MIT; see fonts/LICENSE-98css.txt.
- Notepad, FolderOpen, Mail, Computer, and Camera: @react95/icons 2.2.0, https://github.com/React95/React95. Native 16px and 32px PNG variants; see pixel-icons/LICENSE-React95.txt.
- Assets are served locally; the portfolio makes no runtime font or icon requests to third-party CDNs.
